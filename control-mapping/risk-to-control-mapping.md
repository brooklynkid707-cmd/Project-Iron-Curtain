# Risk-to-Control Mapping

Project Iron Curtain maps identified organizational risks to security controls based on their ability to reduce likelihood, impact, or both.

| Risk | Security Control | Example Technologies |
|---|---|---|
| Malware infection | Endpoint Detection & Response | CrowdStrike Falcon / SentinelOne / Microsoft Defender |
| Phishing attacks | Secure Email Gateway | Proofpoint / Mimecast / Microsoft Defender Email |
| Unauthorized network access | Next Generation Firewall | Palo Alto Networks / Fortinet / Cisco Firepower |
| Credential theft | Multi-Factor Authentication | Okta / Duo Security / Microsoft Entra |
| Data exfiltration | Data Loss Prevention | Symantec DLP / Microsoft Purview / Forcepoint |
| Lack of centralized monitoring | SIEM | Splunk / IBM QRadar / Microsoft Sentinel |

## Control Selection Principle

Controls were selected to address specific risk exposures rather than being treated as isolated technology purchases.

The combined architecture provides protection across:

- Endpoints
- Networks
- Identity
- Email
- Sensitive information
- Cloud environments
- Security monitoring

## Vendor Context

Products listed in this repository are technologies evaluated or proposed in the capstone.

Their inclusion does not imply that each product was purchased or deployed in a production environment.
