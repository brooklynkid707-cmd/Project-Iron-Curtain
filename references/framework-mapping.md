# Framework Mapping

Project Iron Curtain uses recognized cybersecurity frameworks and security principles to support the proposed enterprise security program.

## NIST Cybersecurity Framework

The capstone uses NIST-aligned security concepts to organize risk management, protection, monitoring, response, and continuous improvement.

Project activities align conceptually with:

- Identify - Asset and risk identification
- Protect - Preventive security controls
- Detect - SIEM and SOC monitoring
- Respond - Incident-response procedures
- Recover - Restoration and continuous improvement

## CIS Critical Security Controls

CIS security-control concepts support the selection and evaluation of safeguards across endpoints, networks, identity, monitoring, and data protection.

## MITRE ATT&CK

ATT&CK can provide adversary-behavior context when developing monitoring and detection use cases.

## Defense-in-Depth

Project Iron Curtain combines preventive, detective, and corrective controls rather than relying on a single defensive technology.

## Important Scope Note

Framework references describe alignment of the proposed security strategy.

They do not represent formal certification or compliance attestation.
