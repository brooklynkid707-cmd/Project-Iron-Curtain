# Executive Summary

Project Iron Curtain is a proposed enterprise cybersecurity framework designed around structured risk assessment and risk-to-control mapping.

The assessment identified material risks involving malware, phishing, ransomware, intellectual property theft, unauthorized access, cloud data exposure, insider threats, and weak authentication.

Rather than approaching cybersecurity as a collection of unrelated technology purchases, Project Iron Curtain maps risks to coordinated preventive, detective, and corrective controls.

The proposed architecture incorporates Endpoint Detection & Response, Secure Email Gateway technology, Next Generation Firewalls, Multi-Factor Authentication, Data Loss Prevention, centralized SIEM monitoring, SOC processes, incident response, organizational governance, and Secure SDLC monitoring.

The resulting strategy is designed to improve security visibility, strengthen protection of critical assets, establish formal response responsibilities, and create a scalable security operating model.

This repository documents the risk methodology, control architecture, governance model, monitoring strategy, and incident-response design developed through the capstone.
