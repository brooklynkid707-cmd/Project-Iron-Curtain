# Evidence

This directory is reserved for sanitized evidence supporting Project Iron Curtain.

Potential portfolio evidence may include:

- Risk assessment artifacts
- Risk-to-control mapping
- Security architecture diagrams
- Control implementation planning
- Monitoring architecture
- Governance models
- Incident-response workflows
- Secure SDLC monitoring concepts

## Publication Review

Before evidence is published, review it for:

- Credentials
- Passwords
- API keys
- Tokens
- Personal information
- Email addresses
- Public IP addresses
- Internal infrastructure details
- Subscription or tenant identifiers
- Confidential academic or organizational information

Evidence should demonstrate the work without exposing unnecessary sensitive information.
