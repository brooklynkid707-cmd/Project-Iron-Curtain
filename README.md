# Project Iron Curtain

## Enterprise Cybersecurity Risk & Security Architecture Program

Project Iron Curtain is an enterprise cybersecurity strategy and architecture case study designed to show how a reactive environment can be transformed into a risk-driven security operating model.

> **Portfolio context:** This originated from postgraduate cybersecurity capstone work and documents a proposed architecture and operating model, not a claim that all controls were deployed in production.

## Recruiter Snapshot

**What this proves:** risk assessment, risk prioritization, defense-in-depth architecture, risk-to-control mapping, SIEM/SOC strategy, incident response, Secure SDLC concepts, governance, and executive communication.

## Major Risk Areas
The case assessment addresses malware, phishing, ransomware, intellectual-property theft, cloud data breach, unauthorized network access, CRM data leakage, insider threat, and fraudulent transactions.
