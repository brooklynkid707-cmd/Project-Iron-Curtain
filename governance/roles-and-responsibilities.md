# Governance Roles and Responsibilities

Project Iron Curtain treats cybersecurity as a cross-functional organizational responsibility.

## Chief Technology Officer

Responsibilities include:

- Executive security oversight
- Strategic direction
- Resource prioritization
- Security program accountability

## IT Administrators

Responsibilities include:

- Technical security-control implementation
- Security investigation
- System administration
- Incident containment
- Remediation support

## Security Operations

Responsibilities include:

- Monitoring SIEM alerts
- Validating suspicious activity
- Escalating incidents
- Maintaining incident documentation
- Supporting continuous security monitoring

## Human Resources

Responsibilities include:

- Employee policy enforcement
- Security awareness support
- Acceptable-use enforcement
- Employee disciplinary actions when required

## Legal and Privacy

Responsibilities include:

- Regulatory guidance
- Privacy considerations
- Legal compliance
- Incident disclosure guidance

## Governance Principle

Cybersecurity requires coordination between technical teams, leadership, Human Resources, and Legal.

Technical controls alone cannot provide an effective enterprise security program without policy, accountability, and organizational governance.
