# Secure Software Development Lifecycle Monitoring

Ultra-Enablers INC. is represented in the capstone as a software-development organization with proprietary software and development documentation requiring protection.

Project Iron Curtain therefore extends security monitoring into the development lifecycle.

## Monitoring Areas

Security visibility should include:

- Source-code repositories
- Developer authentication activity
- Repository access
- Unauthorized code downloads
- Abnormal repository access patterns

## Security Objective

The objective is to protect proprietary software and development artifacts from unauthorized access, insider threats, credential compromise, and intellectual property theft.

## Integration With Security Operations

Development security telemetry should feed the broader monitoring strategy where appropriate.

Suspicious development activity can then be correlated with identity, endpoint, network, and other security telemetry.

## Principle

Secure development monitoring expands cybersecurity beyond infrastructure protection and helps protect the intellectual property that supports the organization's business value.
